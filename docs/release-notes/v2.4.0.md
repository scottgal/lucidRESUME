# lucidRESUME 2.4.0

This minor release makes the reviewed JobML career record usable in a local,
job-description-to-resume flow with durable links back to its source prose.

## Resume compilation

- Selects role-specific prose from accepted career claims, keeps a compact
  chronology without duplicate roles, and adds a Core Skills index whose links
  resolve to the rendered prose.
- Adds optional local Ollama editing in two bounded passes. Each section keeps
  its selected claim and evidence identities; unsupported vacancy terms,
  invented numbers, and edits over the section budget are rejected.
- Produces an application-specific evidence page with full JobML, compact cJobML,
  the complete Markdown transcript, ordered SHA-256 source chunks, and Markdown,
  Word, and PDF downloads. Word and PDF retain the verification URL.

## Local import and integration

- Replaces the hosted Jev decision adapter with optional local Ollama Nimble for
  bounded section, entity, and skill-category decisions during import. Nimble
  cannot create claims or evidence and is disabled by default.
- Adds a local run script for the adjacent Mostlylucid site. Its separate gateway
  maps `/resume` to the compiler and supports authenticated public writes or an
  explicit loopback-only local writer mode.
- Keeps sample snapshots and generated publications under Git-ignored
  `App_Data`; personal career records are not release assets.

## Validation

- 492 .NET tests passed locally across the solution.
- The real local flow published a 16-section resume from a private reviewed
  career record and a pasted AI engineering job description. The evidence page,
  JobML, cJobML, transcript, source-chunk manifest, and all three downloads
  returned successfully. All 24 source chunks reassembled to the transcript's
  SHA-256 hash, and all 13 displayed skill links resolved to prose sections.

The prose editor improves selected passages but is still evidence-bounded. Its
summary may need human review for tone and brevity; the compiler does not claim
to establish job eligibility or generate missing experience.
