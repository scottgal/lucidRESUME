# lucidRESUME 2.2.0

## Dependency and supply-chain hardening

- Removes all known NuGet and npm vulnerabilities from the bundled lucidRAG
  dependency graph, including critical and high-severity transitive findings.
- Updates the .NET 10 dependency family, Hot Chocolate, OpenTelemetry, Avalonia,
  SQLite, MailKit, MimeKit, Puppeteer, Vite, PostCSS, and Mermaid to patched
  compatible releases.
- Regenerates and validates the embedded Mermaid parser against the patched
  browser-side dependency graph.

## Continuous verification

- Adds a CI security gate covering direct and transitive NuGet dependencies and
  every npm lockfile in lucidRAG.
- Adds weekly grouped Dependabot updates for NuGet, npm, and GitHub Actions.
- Retains deterministic resume compilation and evidence-led JobML projection;
  no rendering path was changed to re-infer evidence.

## Validation

- The complete lucidRESUME solution builds with zero warnings and zero errors.
- All 379 lucidRESUME tests pass.
- Dependency-sensitive lucidRAG suites pass, including DoomSummarizer, SQLite,
  Mermaid, LucidResearch, document summarization, and code summarization.
- Clean npm installs, production frontend builds, and all dependency audits pass.
