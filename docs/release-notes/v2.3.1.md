# lucidRESUME 2.3.1

This is the published build of the 2.3 release line. It contains the complete
2.3.0 feature set plus a release-pipeline correction for headless Chrome.

## Human prose and evidence

- Keeps reviewed human prose authoritative while exposing evidence-linked
  JobML and optional compact cJobML for ATS and AI consumers.
- Adds scientific-style inline citations and compact references to Markdown,
  Word, and PDF output, with an optional link to the complete career record.
- Compiles role-specific resumes as projections of accepted ledger evidence.
  Rendering does not re-infer the candidate or promote generated text to fact.

## Complete transcripts and reviewed import

- Adds the portable JobML `career_record` profile, complete-record publication
  endpoints, drift hashes, semantic spaces, role centroids, repository evidence,
  and package-registry observations.
- Adds `Reviewed` import mode for a human-checked complete transcript. Reviewed
  identity and dates can supersede stale resume variants while original evidence
  remains unchanged.
- Routes every source through explicit merge review and persists manual role
  identity and date corrections.

## Resume compiler and output

- Adds the minimal ASP.NET Core compiler and publication control for turning a
  complete career record plus a pasted vacancy into an evidence-bounded resume.
- Supports deterministic selection and optional bounded OpenAI or local grug 9B
  tightening passes, with per-section validation and safe fallback.
- Produces conventional ATS-oriented Markdown, DOCX, and PDF output with a
  minimum two-page layout, compact chronology, selected publications, optional
  citations, and career-record links.
- Extracts target titles from flattened pasted adverts without depending on
  optional NER assets.

## Additional tooling

- Adds explainable GitHub repository quality analysis and NuGet package-family
  evidence without treating popularity or unattributed forks as competence.
- Adds bounded Jev-assisted parsing experiments, benchmarks, operating-system
  keyring storage for API keys, and an experimental Chrome Prompt API evidence
  filler that never submits forms or fills unsupported sensitive answers.
- Updates the Avalonia editor, import review, live evidence linking, manuals,
  specifications, ATS research, and single-page documentation archive.

## Validation

- 479 .NET tests pass across 12 projects.
- Release validation builds with warnings treated as errors, verifies formatting,
  and audits transitive dependencies.
- The Chrome extension passes TypeScript checks, unit tests, its build, and a
  headless Greenhouse, Lever, and Workable form-shape matrix using a temporary
  browser profile.
- Release archives exclude credentials, databases, personal ledger snapshots,
  and generated JobML records.
