# lucidRESUME 2.5.0

This release makes the complete career transcript the saved source for resume
generation, adds role interviews and a generated-document archive, and fixes the
full JobML editing workflow.

## Complete career and stronger evidence

- Composes and deduplicates legacy imports once, then reconciles reviewed changes
  at save time. Generation, matching and planning read the saved career instead
  of rescanning imported resumes for every job.
- Retains detailed role prose, named skills, complete interview answers, original
  evidence bindings, review decisions and model-specific semantic indexes.
- Adds focused job-gap interviews and a job-independent complete-transcript builder.
  Reviewed accounts return to the correct role and can support later resumes.
- Uses accepted concepts and audited equivalents for required skill coverage.
  Embeddings retrieve related evidence; similarity does not establish a required skill.
- Connects GitHub README passages, technology candidates, project age/activity and
  bounded contribution observations. Extracted technology claims require review;
  repository age does not become personal skill-years.

## Generation, editing and saved versions

- Reuses validated prose accounts tied to source facts, supported skills, evidence,
  model identity and editing purpose. Unsupported edits retain source wording.
- Opens the full career JobML in the editor, preserves machine detail and embeddings,
  displays claim-anchored prose, and publishes reviewed achievement/summary edits
  back to the career with stale-revision protection.
- Saves generated versions separately from inputs, including the job, frozen career
  evidence, DOCX, PDF, JobML and rendered pages. Reopen the saved Word/PDF and follow
  citations to original source excerpts without generating again.
- Fixes asynchronous service disposal in CLI commands and the pipeline's incorrect
  automatic-event label on manual notes and stage changes.
- Tests extracted, signed Mac archives on Intel and Apple Silicon, including native
  SQLite/sqlite-vec loading, migration, persistence, vector searches and restart.
  Adds an isolated `--storage-audit` diagnostic for packaged storage failures.

## Upgrade and backup

Mac bundles now correctly declare macOS 14 as their minimum, matching the shipped
Apple Silicon vector library. The previous macOS 12 declaration was incorrect.

Before upgrading, close the app and back up its app data directory, including
`data.db`, `generated-resumes/` and `prose-library/`. JSON/database-only backups
contain structured records and archive metadata, but not the archived document files.
The first updated launch creates the definitive career record from legacy imports.
Malformed entries remain in source archives; invalid legacy JobML requires review.
Deleting an input archive does not silently retract incorporated career facts.

## Validation and limits

Local validation covers 598 .NET tests, 21 offline CLI workflows, 13 native client
workflow groups, a real browser compiler flow, 22 extension tests and three ATS
form shapes. Final CI passed on Windows, Linux and macOS, including all 21 CLI
workflows and 13 native client groups on each OS. All six platform archives built;
the signed macOS arm64 bundle also passed packaged native workflows. See the
[validation report](../reviews/2026-10-12-v2.5-validation.md) for run links and coverage limits.

Native full-career measurements were 164.89 seconds for fresh local-model prose
editing and 1.75 seconds for an identical repeat including archive persistence.
New jobs and different models can take longer. Word and PDF pagination can differ.
The Morena regression produces a plausible grounded draft; stronger production-agent,
evaluation, safety and outcome accounts still need author input. These checks do
not certify an application's quality or job eligibility.
