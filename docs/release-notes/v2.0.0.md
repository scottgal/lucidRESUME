# v2.0.0 Release Notes

## Evidence-first resume workspace

lucidRESUME 2.0 introduces JobML, a machine-readable evidence layer embedded at
the end of an ordinary Markdown resume. Human prose remains authoritative, while
claims can retain more detail and link to exact prose passages or external
sources.

- Edit prose and JobML side by side in the new three-pane evidence editor.
- Follow reciprocal links between prose passages, claims, and evidence.
- Detect valid, changed, missing, and ambiguous evidence after editing.
- Use fast evidence fingerprints to detect drift without treating hashes as
  attestations.
- Preserve namespaced JobML extensions without losing their payloads.

## Complete resume generation pipeline

- Import and merge multiple PDF, DOCX, Markdown, text, LinkedIn, and GitHub
  sources into one evidence ledger.
- Parse resumes with deterministic extraction, ONNX models, OpenAI, or the local
  LLamaSharp Grug 9B provider.
- Paste a job description and create evidence-constrained, role-specific prose.
- Export complete Markdown, professionally formatted DOCX, and PDF artifacts.
- Add a visible MACHINE AREA containing the embedded JobML and its explanatory
  link.

## JobML 0.1

This release includes the normative JobML 0.1 specification, JSON Schema, and a
GitHub repository extension. The extension keeps repository facts, quality
assessments, inferred skill observations, and reviewed claims separate. Language
statistics, stars, topics, dependencies, and README text do not silently become
claims of authorship or proficiency.

## Validation and tooling

- Expanded the Avalonia UI automation framework with stronger locators,
  scrolling, screenshots, SVG capture, and playback diagnostics.
- Added visual flows for multiple-resume import, output generation, the linked
  JobML editor, and the in-app manual.
- Added regression coverage for JobML parsing, drift reconciliation, output
  generation, multi-source merge behavior, OpenAI responses, and LLamaSharp
  integration.

JobML 0.1 is experimental. Review generated prose and inferred claims before
using a resume in an application.
