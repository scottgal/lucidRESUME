# v2.0.2 Release Notes

## Release and documentation hardening

- Updated the README to describe the shipped evidence-led projection model,
  privacy boundaries, current downloads, macOS app bundle, and first-run model
  cache accurately.
- Added shields for the current lucidRESUME release and the published Avalonia UI
  testing framework.
- Updated GitHub workflows to maintained Node 24 action versions and pinned Linux
  jobs to Ubuntu 24.04.
- Restored the SQLite JSON migration test to CI and release validation. The patch
  release now runs the complete test suite without exclusions.

## Integrity model

- Ingestion may use deterministic extraction, NER, and an explicitly configured
  LLM to propose ledger records.
- Inferred records retain provenance and require review.
- Rendering remains a strict projection of accepted ledger data. It never reruns
  NER or an LLM, and stale evidence prevents export.

- Release build and complete solution test suite pass locally.
- Dependency audit reports no known vulnerable direct or transitive packages.
- Release archives remain gated by the packaged Avalonia UI smoke test and macOS
