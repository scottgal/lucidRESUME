# v4.0.0 Release Notes

## Career evidence compiler

- Added `lucidRESUME.Compiler`, a deterministic compiler from a complete, reviewed Markdown + JobML master to a role-specific projection.
- Added `lucidRESUME.Web`, a minimal ASP.NET Core control for publishing immutable ledger revisions, pasting a job description, previewing the projection, and downloading Markdown, Word, or PDF.
- Selection starts from accepted, drift-free evidence. Unsupported requirements remain explicit gaps.
- Optional OpenAI and in-process grug 9B passes edit only selected source prose. Claim IDs, evidence IDs, numbers, sections, unsupported vacancy terms and word budgets are validated after each pass.
- Local grug edits run section by section so the 9B model receives a small, bounded task rather than an entire resume.

## Role profiles and output quality

- Added shipped centroid seeds for Lead Developer, Head of Engineering, CTO and VP of Engineering.
- Role centroids are materialised locally with the configured embedder and influence evidence ranking, not claim creation.
- Collapsed overlapping taxonomy aliases so a short requirement no longer expands into dozens of nested pseudo-skills.
- Capped detailed experience to the seven strongest roles, rejected malformed legacy-parser roles, limited bullets, and selected role-relevant summary sentences from the original prose.
- Added repeatable Lead Developer, Head of Engineering and CTO job-description fixtures.

## Portable product assets

- Added `lucidRESUME --asset-audit` and a release-matrix gate for the taxonomy, priorities, role profiles, entity lists, GitHub mapping, dictionaries and prose-quality lists.
- Release validation rejects user databases, JobML ledger snapshots and credential-like files.
- Added atomic model downloads and automatic repair of invalid ONNX cache files.
- Documented the clean-install boundary and Kaggle/LinkedIn dataset provenance.

## cJobML

- Endpoint-only cJobML projections are now valid: accepted claims can publish a compact `Full JobML` link even when no public external citation is selected.

## Verification

- 356 solution tests pass.
- Live OpenAI tests pass for grounded resume output, cold cJobML parsing and bounded composition.
- The installed grug 9B GGUF passes a bounded single-section composition test.
- A self-contained macOS ARM64 publish passes the clean-install asset audit.
