# lucidRESUME 2.1.0

## Evidence-led resume projection

- Builds role-specific resumes from the persistent evidence ledger instead of
  re-inferring evidence while rendering.
- Uses accepted human prose as the source material. Optional local or cloud
  editing is bounded to the already selected evidence.
- Includes compact cJobML citations and a References section in Markdown, Word,
  and PDF by default. Use `--cjobml false` or the editor toggle for a human-only
  copy.
- Keeps detailed selectors, passages, and drift fingerprints in full JobML while
  compact output cites imported resume sources and public evidence.

## Import and matching quality

- Improves headings, compact role lines, dates, current roles, skills sections,
  and fallback parsing for ordinary Word resumes.
- Adds shipped leadership vocabulary for Lead Developer, Head of Engineering,
  CTO, and VP Engineering matching. No personal resume or ledger data ships with
  the application.
- Improves merge provenance and avoids turning weak template hints into empty
  structured resumes.

## Editor and export

- Adds a live cJobML include/exclude control to the Project editor.
- Keeps the Markdown, DOCX, and PDF outputs on the same deterministic projection.
- Corrects DOCX structure and verifies generated files with Word-compatible
  Open XML checks and LibreOffice conversion.

## macOS packaging

- Keeps `libAvaloniaNative.dylib` and the other runtime libraries inside the app
  bundle instead of extracting them on first launch.
- Ad-hoc signs each native library, the executable, and the completed app bundle.
- Verifies the native library, bundle signature, asset audit, and packaged UI
  smoke test before publishing an archive.

## Validation

- 371 automated tests across 11 projects.
- A 48-action Avalonia acceptance script covers import, projection, evidence
  links, cJobML toggling, and live document output.
- Local quality runs produced and opened Lead Developer, Head of Engineering,
  and CTO variants in Markdown, DOCX, and PDF.
