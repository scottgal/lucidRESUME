# lucidRESUME 2.0.4

## Live Word preview in the JobML editor

- The JobML editor now opens imported resumes on a **Document** tab containing
  the current Word-layout projection.
- Markdown edits are debounced, exported to DOCX with the selected resume
  template, and rendered into pages by Morph.
- **Write** and **Markdown** tabs remain available beside the live document.
- Template changes affect presentation only. They do not rerun extraction,
  reinterpret evidence, or rewrite human prose.
- Page navigation covers the complete exported artifact, including its labelled
  machine area.

## Reliability

- Preview generations are cancellation-aware, preventing an older render from
  replacing the current revision.
- Opening another resume clears stale preview pages while the new projection is
  prepared.
- Stable JobML heading anchors such as `{#candidate-name}` are no longer printed
  as part of the candidate name in DOCX or PDF projections.
- New Avalonia UI coverage imports a real DOCX, opens JobML, waits for the live
  Word render, and verifies that the document, evidence links, and JobML panes
  are visible together.
